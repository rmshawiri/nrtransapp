**Produit :** NR-TRANS

---

# 1. OBJECTIF DE LA CHARTE

Cette charte graphique définit l'identité visuelle à respecter pour l'ensemble de l'écosystème NR-TRANS :

- Landing Page ;
- application NR-TRANS ;
- espace Client ;
- espace Administrateur ;
- PWA ;
- formulaires ;
- page d'inscription ;
- pages d'abonnement ;
- emails et notifications visuelles ;
- captures d'écran ;
- supports marketing futurs.

NR-TRANS appartient à l'écosystème MORA Shawiri.

La plateforme doit donc conserver la palette principale de MORA Shawiri tout en développant une identité propre, immédiatement reconnaissable comme liée au domaine du transport, de la gestion et de la rentabilité.

Le design recherché doit être :

- moderne ;
- premium ;
- professionnel ;
- captivant ;
- rassurant ;
- dynamique ;
- propre ;
- accessible ;
- adapté au secteur du transport ;
- parfaitement utilisable sur ordinateur et smartphone.

Le design ne doit pas être surchargé.

NR-TRANS doit donner l'impression d'un véritable produit SaaS professionnel et non d'un simple tableau de gestion.

# 3. LOGO PRINCIPAL NR-TRANS

Le logo principal est constitué notamment de :

- un véhicule blanc ;
- une grande courbe verte ;
- une courbe jaune/or ;
- une route bleue ;
- une flèche ascendante blanche ;
- des barres de progression jaunes/or ;
- le nom `NR-TRANS` ;
- le slogan :
  `Gestion simple. Trajets rentables.`

Le logo possède un FOND TRANSPARENT.

Cette caractéristique doit impérativement être prise en compte dans toutes les interfaces.

Le fond transparent ne signifie PAS que le logo peut être placé sur n'importe quelle couleur.

Certains éléments du logo sont :

- bleu foncé ;
- blanc ;
- jaune/or ;
- vert ;
- gris clair.

Le contraste avec le fond doit donc être vérifié avant toute utilisation.

---

# 4. RÈGLE CRITIQUE — FOND DU LOGO

Le logo principal transparent doit être utilisé de préférence sur un fond :

- blanc ;
- blanc cassé ;
- gris extrêmement clair ;
- surface claire neutre.

Exemples recommandés :

`#FFFFFF`

`#F8FAFC`

`#F5F7FA`

Ces surfaces permettent de conserver une excellente lisibilité de l'ensemble du logo.

IMPORTANT :

Le slogan du logo est bleu foncé.

Il risque de devenir peu visible ou invisible sur un fond bleu foncé.

De même, la flèche et certaines parties du véhicule sont blanches.

Un fond entièrement blanc peut donc réduire légèrement le contraste de certains détails blancs, mais reste préférable grâce aux contours et aux autres éléments graphiques du logo.

La priorité est de préserver la lisibilité du logo complet.

---

# 5. UTILISATION SUR FONDS FONCÉS

NE PAS déposer directement le logo principal transparent sur un grand fond bleu foncé sans vérifier son contraste.

En particulier, éviter :

`Logo transparent → directement sur #003366`

car certaines parties bleues du logo et notamment le slogan risquent de se confondre avec le fond.

Lorsque le design utilise un fond bleu foncé, placer le logo principal dans une surface claire dédiée.

Exemple conceptuel :

┌──────────────────────────────┐
│ FOND BLEU #003366            │
│                              │
│   ┌──────────────────────┐   │
│   │  SURFACE BLANCHE     │   │
│   │                      │   │
│   │   LOGO NR-TRANS      │   │
│   │                      │   │
│   └──────────────────────┘   │
│                              │
└──────────────────────────────┘

Cette surface peut être :

- une carte blanche ;
- un conteneur clair ;
- un badge ;
- une zone de navigation claire ;
- une surface légèrement translucide mais suffisamment opaque.

Elle peut avoir :

- coins arrondis ;
- légère ombre ;
- bordure discrète.

Elle ne doit pas donner l'impression que le logo possède artificiellement un gros rectangle blanc disgracieux.

Le traitement doit être élégant.

---

# 6. ZONE DE PROTECTION DU LOGO

Toujours conserver suffisamment d'espace autour du logo.

Aucun élément ne doit toucher directement :

- le véhicule ;
- la courbe ;
- la flèche ;
- le texte NR-TRANS ;
- le slogan.

Éviter de placer immédiatement autour du logo :

- bouton ;
- texte ;
- bordure ;
- icône ;
- image ;
- graphique.

Le logo doit respirer.

Pour l'intégration Web, prévoir une zone de protection visuelle proportionnelle à sa hauteur.

---

# 7. REDIMENSIONNEMENT DU LOGO

Toujours conserver le ratio original.

INTERDIT :

- étirer horizontalement ;
- étirer verticalement ;
- écraser ;
- rogner une partie ;
- déformer ;
- incliner ;
- modifier les proportions.

Utiliser :

`object-fit: contain`

lorsque nécessaire.

Ne jamais utiliser :

`object-fit: cover`

si cela provoque le rognage du logo.

---

# 8. LOGO ET NAVIGATION

Le logo principal complet peut être utilisé dans les endroits disposant de suffisamment d'espace :

- Landing Page ;
- footer ;
- page de connexion ;
- inscription ;
- espace Client ;
- documents ;
- page À propos.

Dans une navigation très compacte, notamment sur mobile, privilégier le favicon ou une représentation compacte plutôt que de rendre le logo principal tellement petit que son slogan devient illisible.

Le logo principal ne doit jamais être affiché dans une taille où le slogan devient une ligne illisible.

# 17. HIÉRARCHIE TYPOGRAPHIQUE

Les titres doivent être nets et relativement compacts.

Le H1 d'une Landing Page peut être fort et expressif.

Les interfaces de gestion doivent cependant privilégier la lisibilité.

Éviter :

- textes trop petits ;
- énormes titres dans l'application ;
- trop de majuscules ;
- trop de gras ;
- espacements excessifs.

Les chiffres financiers importants doivent être immédiatement identifiables.

Exemple :

Revenus du mois

**245 000 KMF**

+12,5 % par rapport à la période précédente

# 22. FORMULAIRES

Les formulaires sont une partie essentielle de NR-TRANS.

Ils doivent être :

- élégants ;
- clairs ;
- espacés ;
- simples ;
- rassurants.

Chaque champ doit disposer d'un label visible.

Prévoir clairement :

- état normal ;
- focus ;
- erreur ;
- succès ;
- désactivé.

Les erreurs doivent apparaître près du champ concerné.

Ne pas afficher uniquement :

`Erreur`

Préférer :

`Saisissez un numéro de téléphone valide.`

---

# 23. FORMULAIRE D'INSCRIPTION

La page d'inscription doit recevoir un traitement visuel premium particulier.

Elle ne doit pas ressembler à un formulaire administratif classique.

Utiliser une expérience progressive.

Exemple :

ÉTAPE 1
Votre compte

ÉTAPE 2
Votre activité

ÉTAPE 3
Votre formule

ÉTAPE 4
Durée

ÉTAPE 5
Code promo

ÉTAPE 6
Récapitulatif

ÉTAPE 7
Paiement

Afficher une progression claire.

Exemple :

`3 / 7`

ou une barre de progression élégante.

Les transitions peuvent être légèrement animées.

Ne pas utiliser d'animations longues ou distrayantes.

---

# 24. SÉLECTEUR D'ABONNEMENT

Les offres doivent être présentées avec des cartes premium.

## Gratuit

Design simple et rassurant.

Mettre en évidence :

`7 jours gratuits`

## Avancé

Mettre en évidence :

`1 véhicule`

et les différents tarifs.

## VIP

Utiliser l'or comme accent premium.

Mettre en évidence :

`Véhicules illimités`

Ne pas rendre toute la carte jaune.

Utiliser l'or pour :

- bordure ;
- badge ;
- icône ;
- prix ;
- petit accent ;
- CTA lorsque le contraste le permet.

---

# 25. SÉLECTEUR DE DURÉE

Pour Avancé et VIP, proposer clairement :

- 1 mois ;
- 3 mois ;
- 6 mois ;
- 1 an.

Le changement de durée doit mettre immédiatement à jour le prix.

Les économies doivent pouvoir être mises en valeur visuellement.

Exemple :

3 mois
**6 000 KMF**
Économisez 1 500 KMF

Les informations doivent être calculées à partir des tarifs officiels et non écrites manuellement à plusieurs endroits du code.

# 26. CODE PROMO

Le champ code promo doit être visible sans perturber le parcours.

Exemple :

`Vous avez un code promo ?`

✓ Code appliqué

Réduction :
−1 000 KMF

Le vert peut être utilisé pour signaler un code valide.

Une erreur doit être claire :

`Ce code promo n'est pas valide pour cette formule.`

# 28. ESPACE CLIENT

L'espace Client doit reprendre le même design system que NR-TRANS.

Éviter de donner l'impression que l'utilisateur quitte l'application pour entrer dans un second produit.

Prévoir une navigation claire vers :

- mon compte ;
- abonnement ;
- commandes ;
- paiements ;
- utilisateurs ;
- avis ;
- sécurité ;
- assistance.

Les informations liées à l'abonnement doivent être visuellement faciles à comprendre.

---

# 29. ESPACE ADMINISTRATEUR

L'administration doit conserver l'identité NR-TRANS tout en étant plus sobre.

Objectif :

efficacité + densité maîtrisée.

Les tableaux administratifs peuvent être plus denses que les écrans Client, mais doivent rester lisibles.

Prévoir :

- filtres ;
- recherche ;
- badges de statut ;
- actions contextuelles ;
- pagination lorsque nécessaire ;
- confirmations.

Les statuts doivent disposer d'une présentation cohérente dans toute l'administration.

---

# 30. NAVIGATION PC

Sur ordinateur, une sidebar moderne peut être utilisée pour l'application.

Elle peut utiliser le bleu `#003366`.

ATTENTION :

Si la sidebar est bleue, NE PAS y déposer directement le logo principal transparent complet si son slogan devient illisible.

Solutions recommandées :

1. utiliser le favicon dans la sidebar ;
2. utiliser le logo complet dans une zone claire ;
3. utiliser un header clair pour le logo complet.

Le favicon est particulièrement recommandé lorsque la sidebar est compacte.

---

# 31. NAVIGATION MOBILE

Sur smartphone :

- priorité au contenu ;
- navigation facile au pouce ;
- boutons suffisamment grands ;
- actions importantes accessibles rapidement.

Une bottom navigation peut être utilisée lorsque pertinente.

Limiter le nombre d'éléments principaux visibles.

Les fonctions supplémentaires peuvent être regroupées dans :

`Plus`

ou un menu secondaire.

---

# 32. MODE CLAIR

Le mode clair doit constituer la référence principale du design.

Base :

- fond très clair ;
- cartes blanches ;
- texte foncé ;
- bleu comme couleur dominante ;
- vert et or comme accents.

Ce mode est particulièrement adapté au logo principal transparent.

---

# 33. MODE SOMBRE

Si le mode sombre est implémenté, il doit être conçu réellement et non obtenu par simple inversion des couleurs.

ATTENTION AU LOGO.

Le logo principal transparent ne doit pas être déposé directement sur une surface sombre si certaines parties deviennent illisibles.

Dans ce cas :

- utiliser une carte claire derrière le logo ;
- ou utiliser le favicon lorsque l'espace est réduit.

Le mode sombre doit conserver :

- contraste ;
- hiérarchie ;
- lisibilité ;
- identité de marque.

---

# 34. LANDING PAGE

La Landing Page peut être plus expressive visuellement que l'application.

Elle peut utiliser :

- grandes typographies ;
- gradients subtils ;
- halos très légers ;
- illustrations ;
- mockups ;
- captures réelles ;
- animations discrètes ;
- formes inspirées de la route et de la progression.

Cependant, éviter :

- effets excessifs ;
- trop de couleurs ;
- animations permanentes ;
- esthétique gaming ;
- néons excessifs ;
- surcharge.

NR-TRANS est un outil professionnel de gestion.

# 36. ICÔNES

Utiliser une seule famille d'icônes cohérente.

Style recommandé :

- moderne ;
- simple ;
- lignes propres ;
- facilement identifiable.

Éviter de mélanger plusieurs bibliothèques avec des styles très différents.

Les icônes doivent accompagner les textes, pas les remplacer lorsque leur signification pourrait être ambiguë.

---

# 37. ARRONDIS

Le logo et le favicon utilisent des formes arrondies.

Le design peut donc employer des rayons modernes.

Cependant, éviter des arrondis excessifs donnant une apparence enfantine.

Les mêmes familles de rayons doivent être utilisées de manière cohérente pour :

- boutons ;
- cartes ;
- champs ;
- modales ;
- badges.

---

# 38. OMBRES

Utiliser des ombres légères.

Objectif :

- profondeur ;
- séparation ;
- hiérarchie.

Éviter :

- grosses ombres noires ;
- effets 3D excessifs ;
- glow permanent.

Le logo possède déjà une esthétique visuelle riche.

L'interface doit rester plus sobre autour de lui.

# 41. TABLEAUX

Sur PC :

utiliser des tableaux lorsque cela améliore réellement la lecture.

Sur mobile :

ne pas forcer systématiquement un tableau large dans un écran étroit.

Transformer les lignes en :

- cartes ;
- listes structurées ;
- vues détaillées ;

lorsque cela améliore l'expérience.

Les informations financières importantes doivent être alignées et faciles à comparer.

---

# 42. DONNÉES FINANCIÈRES

Les montants doivent être formatés de manière cohérente.

Exemple :

`125 000 KMF`

et non :

`125000`

Préserver la cohérence dans toute l'application.

Les nombres importants peuvent utiliser Outfit pour renforcer leur visibilité.

---

# 43. ÉTATS VIDES

Ne jamais laisser une grande zone vide sans explication.

Exemple :

Aucun véhicule enregistré

`Ajoutez votre premier véhicule pour commencer à suivre votre activité.`

[Bouton : Ajouter un véhicule]

Les états vides doivent aider l'utilisateur à avancer.

---

# 44. MICRO-INTERACTIONS

Autoriser des micro-interactions discrètes :

- hover ;
- changement de sélection ;
- validation ;
- apparition d'une carte ;
- progression ;
- succès.

Durées courtes.

Éviter les animations décoratives répétitives.

Le produit doit paraître fluide, pas agité.

---

# 45. RESPONSIVE DESIGN

Le design doit être conçu dès le départ pour :

- smartphone ;
- tablette ;
- ordinateur portable ;
- grand écran.

Ne pas construire uniquement une version PC puis tenter de la réduire.

Les écrans mobiles doivent être réellement pensés pour le mobile.

---

# 46. ACCESSIBILITÉ

La fidélité à la marque ne doit jamais passer avant la lisibilité.

Vérifier :

- contraste ;
- taille des textes ;
- focus clavier ;
- labels ;
- états ;
- boutons ;
- formulaires.

Le jaune `#FFD700` ne doit notamment pas être utilisé pour du petit texte sur fond blanc si le contraste devient insuffisant.

---
